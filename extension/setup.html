Claude MCP in Fayar kitsune

Lets Claude (Claude Desktop or Claude Code) use this Firefox: open tabs, read pages, click and type. The extension only talks to the MCP server on this computer (127.0.0.1). What Claude reads from a page goes to Claude, like anything else in your conversation.

Access to all websites Required

Needed to read pages, take screenshots, click and type on the sites Claude visits.

User scripts Optional

Lets javascript_tool run on sites whose security policy blocks it, such as reddit.com. Firefox warns that this allows unverified scripts: those scripts are the code Claude asks to run.

Connection to Claude

Your tabs

Claude works in its own tab group, named "Claude". It can't use your other tabs unless you share them: right-click a tab → Share Tab with Claude, or pick tabs when Claude asks. The same menu stops sharing, and moves tabs between your windows and Claude's: Move Tab to Claude's Window, and on Claude's tabs, Move Tab Out of Claude's Group.

Change these any time in about:addons → Claude MCP in Fayar kitsune → Permissions, or reopen this page from the toolbar button. Source and setup guide
